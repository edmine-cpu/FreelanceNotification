# FreelanceHunt → Telegram

Общедоступный Telegram-бот: каждый пользователь пишет `/start` в личном чате и получает собственную подписку на проекты Freelancehunt. Добавлять Telegram ID новых пользователей на сервере не нужно.

## Личные настройки

Открой **⚙️ Настройки** или отправь `/settings`:

- **Имя и портфолио** — данные автора только для его откликов. Отправь `-`, чтобы очистить поле.
- **Добавить категорию по ID** — например, `99` (веб-программирование) или `180` (разработка ботов). До 30 категорий на пользователя; ненужные категории можно удалить, в том числе все.
- **Имена категорий** — собственные названия выбранных категорий.
- **Уведомления категорий** — отдельное включение/отключение каждой категории.
- Только для владельца AI (**992784212**): **Мой промпт** — инструкции для AI: опыт, стиль, язык и правила откликов. До 3500 символов Telegram.
- Только для владельца AI: **Примеры откликов (JSON)** — личные примеры стиля: `{"examples": [{"input": {"project_title": "Пример"}, "output": "Текст отклика"}]}`. Цены и сроки программа рассчитывает отдельно.

Новый пользователь получает начальные категории из `SKILL_IDS`, нейтральный промпт, пустые примеры, имя и портфолио. Чужие настройки, история отправок, промпты и оценки ему не передаются. Фильтр Python/JavaScript/TypeScript и все AI-функции доступны только ID 992784212, независимо от переноса старого профиля. Остальные пользователи получают обычные уведомления и просмотр всех своих проектов, без AI-запросов.

Для владельца Haiku 4.5 проверяет стек новых проектов. Ошибка проверки пропускает проект в уведомления. Opus 5.5 вызывается только по кнопке **«Сгенерировать ставку»**: один ответ содержит текст и оценку объёма, а программа рассчитывает цену и срок. Повторное открытие возвращает сохранённую ставку.

**«Новый вариант»** отправляет «Напишите корректировки для AI» с кнопками **«Пропустить»** и **«Отмена»**. Следующий текст до 2000 символов направляет одну перегенерацию; цена, часы, курс и сроки остаются прежними. «Пропустить» создаёт новый вариант без пожеланий. Ожидание истекает через 15 минут; команды и переход в меню его отменяют. Бот не публикует ставки на Freelancehunt.

## Команды

- `/start` — открыть меню и возобновить уведомления.
- `/help` — показать меню и помощь.
- `/ai_usage` — расходы AI владельца за сегодня, 7 календарных дней и текущий месяц в Europe/Kyiv.
- `/settings` — личные настройки.
- `/cancel` — отменить текущий ввод и вернуться в настройки.
- `/stop` — остановить свои уведомления, сохранив настройки. Возобновление через `/start`.

Бот работает в личных чатах. Кнопки из групп и чужих чатов не дают доступа к личным данным. Блокировка бота отключает рассылку этому пользователю и не мешает остальным.

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather).
2. Получи токен [Freelancehunt API](https://freelancehunt.com/my/api).
3. Для AI получи ключ прямого API Anthropic и проверь доступность обеих выбранных моделей.
4. Скопируй `.env.example` в `.env` и заполни секреты.
5. Запусти `docker compose up -d --build`.
6. Открой бота в Telegram и отправь `/start`.

Логи: `docker compose logs -f bot`.

## Автодеплой

Push в `main` автоматически обновляет бота на `173.242.51.44` в
`/opt/FreelanceNotification`. Сервер проверяет GitHub раз в минуту, собирает образ,
запускает тесты, сохраняет данные и перезапускает контейнер. При ошибке запуска
возвращается предыдущая версия. Секреты GitHub Actions не требуются.

Инструкции, логи и повторная установка: [deploy/README.md](deploy/README.md).

## Настройки сервера

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | обязательна | Токен бота |
| `FREELANCEHUNT_TOKEN` | обязательна | Общий токен чтения проектов |
| `TELEGRAM_CHAT_ID` | пусто | Только ID прежнего владельца для однократного переноса данных |
| `SKILL_IDS` | `180` | Начальные категории новых пользователей |
| `POLL_INTERVAL` | `60` | Интервал опроса в секундах |
| `STATE_FILE` | `/data/state.json` | Старое состояние; личные данные создаются в соседней папке `users/` |
| `PROMPT_EXAMPLES_FILE` | рядом со `STATE_FILE` | Старые примеры для переноса владельцу |
| `QUOTE_FILE` | `/data/quotes.json` | Старые оценки для переноса владельцу |
| `SEND_EXISTING_ON_FIRST_RUN` | `false` | Присылать ли текущие проекты при первом опросе категории |
| `PAGE_SIZE` | `5` | Размер страницы истории |
| `HISTORY_SIZE` | `50` | Размер истории на категорию у каждого пользователя |
| `ANTHROPIC_API_KEY` | пусто | Ключ Anthropic; без него обычные уведомления продолжают работать |
| `AI_ENABLED` | `true` | Серверный переключатель AI |
| `AI_SCREEN_MODEL` | `claude-haiku-4-5-20251001` | Проверка стека |
| `AI_BID_MODEL` | `claude-opus-5-5` | Оценка и текст ставки |
| `AI_SCREEN_MAX_TOKENS` / `AI_BID_MAX_TOKENS` | `256` / `2048` | Максимальный выход; у Opus включает размышления |
| `AI_BID_EFFORT` | `low` | `low` или `medium`; используется `low`, платное сравнение не запускалось |
| `AI_SCREEN_TIMEOUT_SEC` / `AI_BID_TIMEOUT_SEC` | `30` / `120` | Отдельные таймауты запросов |
| `AI_MONTHLY_ALERT_USD` | `20` | Предупреждения при 80% и 100%; 0 отключает предупреждения |
| `AI_COST_TIMEZONE` | `Europe/Kyiv` | Часовой пояс статистики |
| `AI_MAX_CONTEXT_CHARS` | `60000` | Сумма инструкций, примеров и входных сообщений; превышение отклоняется без обрезки и API |

Секреты хранятся только в серверном `.env`. Рабочего пути Gemini и резервного провайдера нет. Денежный порог **не блокирует AI**, не меняет модель и не является лимитом аккаунта.

Кеш, операции, корректировки и расход хранятся в `ai.sqlite3` рядом со `STATE_FILE` (по умолчанию `/data/ai.sqlite3`). База входит в постоянный том `data/`. Не удаляй её при обновлении. Реальные токены записываются до проверки JSON/текста; неопределённая стоимость отмечается отдельно. Тарифы зафиксированы с версией `anthropic-standard-global-2026-09-28`; старые расходы не пересчитываются.

Максимум две попытки при 429/временных HTTP-ошибках. `Retry-After` больше 30 секунд переводит клиент в паузу без долгого автоматического ожидания. Обрыв транспорта не повторяется автоматически: обработанный провайдером запрос мог быть платным. Ошибки ключа/биллинга/параметров приостанавливают новые сетевые попытки этого клиента на 5 минут. Ошибка проверки стека кешируется как временная неудача на 5 минут.

Локальный кеш исключает вызовы. Кеш префикса Anthropic пока не включён: его экономию нужно подтвердить живой серией запросов с учётом стоимости записи. Поля чтения/записи 5m/1h уже учитываются раздельно. Личные инструкции и все примеры передаются без сокращения; профиль и финальная цена/срок добавляются кодом.

## Обновление существующего бота

На действующем сервере используй установленный [автодеплой](deploy/README.md): он сохраняет копию `data/` и `.env`. Для первичного переноса старой установки укажи прежний положительный `TELEGRAM_CHAT_ID`. При первом запуске данные копируются в `data/users/<TELEGRAM_CHAT_ID>/`:

- `state.json` — категории, названия, отключённые уведомления, история и отметки отправки;
- `bids_examples.json` — личные примеры откликов;
- `system_prompt.md` — прежний промпт;
- `quotes.json` — зафиксированные оценки;
- `user.json` — сведения о регистрации и переносе.

В профиль владельца переносятся использовавшиеся ранее имя Никита и его портфолио. Их можно изменить в Telegram. Исходные файлы остаются на месте; повторный запуск не перезаписывает личные настройки. При откате на код до ограничения доступа сначала отключи AI глобально (в старой версии — `GEMINI_ENABLED=false`) и пересоздай только этот контейнер с сохранённым образом по инструкции автодеплоя. Откат не должен возвращать AI всем пользователям. Данные автоматически не откатывай.

Существующие корректные оценки владельца используются без повторного запроса. Изменение стиля/профиля обновляет текст, сохраняя цену; изменение заголовка, описания или бюджета инвалидирует ставку и оценку только этого проекта. При обычной перегенерации цена остаётся прежней. Существующая формула: 8 USD/час, категории объёма 4/8/16/24/40/80 часов, округление и бюджет как нижняя граница. Для неопределённого ТЗ цена и срок не выводятся.

## Устройство и проверка

`UserRegistry` хранит отдельные папки по Telegram ID. Middleware определяет пользователя по отправителю личного сообщения, передаёт обработчику его хранилище и копию настроек. `PublicNotifier` запрашивает объединение категорий один раз за цикл и отдельно применяет подписки, названия, историю и доступ к AI каждого получателя. Успешный пустой ответ API тоже инициализирует категорию, чтобы следующий первый проект не потерялся.

```sh
pip install -r requirements.txt
python -X utf8 -m unittest discover -s tests
```

Тесты проверяют перенос старых данных, сохранение после перезапуска, изоляцию пользователей и промптов, доступ к настройкам, независимую рассылку, блокировку получателя и расчёт стоимости.

## Статус перехода на Claude

Ключ установлен в серверном `.env`. 2026-09-28 доступ к `claude-haiku-4-5-20251001` и `claude-opus-5-5` подтверждён через Models API: обе модели вернули HTTP 200 с ожидаемым ID. Эта проверка не генерирует текст и не расходует токены. Выпуск выполняется через установленный автодеплой.

По прямому указанию владельца платные smoke tests и сравнение `low`/`medium` на проектах не запускаются. Локально прошли 127 тестов с подменой транспорта; автодеплой также запускает тесты без сети. Настоящий ответ Messages API, качество текста и доступный баланс генерации этой бесплатной проверкой не подтверждаются. Таймауты и предел контекста пока стартовые; процент экономии и месячный расход без замеров не заявляются. Рабочие вызовы учитываются в `/ai_usage`. Opus вызывается только вручную; Haiku проверяет новые проекты владельца без массового пересмотра истории при запуске.

Детали API сверены по официальным источникам: [модель Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview), [тарифы](https://platform.claude.com/docs/en/about-claude/pricing), [effort](https://platform.claude.com/docs/en/build-with-claude/effort), [структурированный вывод](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [учёт кеша](https://platform.claude.com/docs/en/build-with-claude/prompt-caching).
